# chopanとチン経衰弱

2〜4人で遊べる、リアルタイム対戦型の神経衰弱ゲームです。Express と Socket.IO で動作し、ゲーム状態はすべてサーバー側で管理します。

## ローカル起動

Node.js 20以上が必要です。

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開き、別タブまたは別端末から同じルーム番号に参加してください。

テストは以下で実行します。

```bash
npm test
```

## Renderへデプロイ

1. このフォルダーを新しい GitHub リポジトリへ pushします。
2. Render で **New > Blueprint** を選び、リポジトリを接続します。
3. `render.yaml` が読み込まれ、無料Web Serviceとして作成されます。

手動設定する場合は Build Command を `npm ci --omit=dev`、Start Command を `npm start`、Health Check Path を `/health` にします。

無料枠では一定時間アクセスがないと休止し、最初のアクセスに時間がかかることがあります。サーバー再起動時には、メモリ上のルーム情報は消えます。

## 画像の追加

画像なしでも文字とマークでプレイできます。画像ファイルの配置規則は [`public/images/README.md`](public/images/README.md) を参照してください。

## 観戦・OBS配信

ルーム番号をURLに付けて、読み取り専用の観戦画面を直接開けます。

```text
http://localhost:3000/watch/4821
```

Render公開後は `https://サービス名.onrender.com/watch/4821` の形式です。観戦者はプレイヤー人数に含まれず、カード操作もできません。

OBS用のシンプル表示は、観戦画面の「OBS用表示」ボタンから開くか、URLに `?obs=1` を付けて直接開けます。OBSのブラウザソースは1920×1080に設定してください。

```text
https://サービス名.onrender.com/watch/4821?obs=1
```

## 主な仕様

- 4桁ルーム番号、2〜4人、作成者のみ開始可能
- 通常16ペア＋ジョーカー1ペア（計34枚）
- 通常ペアは1点、ジョーカーペアは2点＋残りカードを3秒公開
- ターン、カード配置、判定、得点をサーバーで一元管理
- 判定中・他プレイヤーのターン・全体公開中の操作をサーバー側でも拒否
- 切断プレイヤーのターンを自動スキップ
- 全員同意による再戦、作成者による待機室への復帰
- PC／スマートフォン対応
